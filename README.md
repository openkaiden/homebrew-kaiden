# Homebrew Kaiden

Homebrew tap for the [Kaiden](https://openkaiden.ai) desktop application.

## Installation

```sh
brew tap openkaiden/kaiden
brew install --cask kaiden
```

### Development builds

To install the latest development build:

```sh
brew tap openkaiden/kaiden
brew install --cask kaiden@next
```

## Upgrading

```sh
brew upgrade --cask kaiden
```

Note: Kaiden includes auto-update functionality. Use `brew upgrade --cask --greedy kaiden` to force Homebrew to upgrade even when auto-updates are enabled.

## Uninstalling

```sh
brew uninstall --cask kaiden
```
